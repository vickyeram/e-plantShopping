# e-plantShopping

e-plantShopping is a React-based plant shopping application that allows users to browse plants, add items to a cart, manage item quantities, and view total cart items using Redux Toolkit.

## Features
- Browse plant products
- Add plants to cart
- Increase and decrease quantity
- View total cart quantity

## Technologies Used
- React
- Redux Toolkit
- JavaScript
- HTML
- CSS

## How to Run
1. Clone the repository
2. Run `npm install`
3. Run `npm run dev`
